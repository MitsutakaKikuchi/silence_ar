# 『沈黙の解剖図譜』制作プロセスとAI協働フロー

本作は、人間関係における「沈黙」をテーマとしたWebARインスタレーション作品です。
企画・メタファー構築から始まり、ビジュアル生成、そしてWebAR技術を用いた高度な実装に至るまで、開発の全工程において生成AI（Gemini Pro / Gemini Nano）をクリエイティブパートナーとして活用しました。

以下に、完成に至るまでの具体的なフローとAIとの協働プロセスをまとめます。

---

## 1. コンセプト設計とメタファーの構築（企画フェーズ）
**目的:** 抽象的な感情を、視覚的に表現可能な具体的なメタファーへと変換する。

*   **人間の思考:** 「言わなかった言葉（沈黙）」が持つ両面性（相手を守る優しさと、自身を蝕む呪い）を視覚化したい。
*   **AI（Gemini 3 Pro）への指示:** 「優しさが逆に苦しい」「厳しさが救いになる」といった矛盾する感情を表現するためのメタファーを提案してほしい。
*   **AIからの出力:** 一貫して**「庭園における要素（植物、土、園芸具）」**に置き換えるフレームワークの提示。
    *   *例:* 「厳しい言葉で正される感覚」→「植物の自由を奪いながらも倒れないように支える錆びた鉄の支柱」
*   **成果物:** 現実と深層心理の2層構造（Layer A: 日常 / Layer B: 本音と庭）の確定、「沈黙」にまつわる感情の言語化、全10エピソードの構成およびポラロイドキャプション形式のテキスト完成。

## 2. 視覚素材の生成（ビジュアル生成フェーズ）
**目的:** 2つのレイヤーに対応する対照的なビジュアルを生成し、ARの「透かし」体験の準備をする。

*   **AIへの指示:** 画像生成AI（Gemini Nano Banana Pro）において、Layer AとLayer Bで全く異なる画風を生成するための「プロンプトテンプレート」を設計・出力。
    *   **Layer A（日常）:** `Smartphone photography aesthetic` などを活用し、技術的に不完全ながら感情的なスナップ写真を生成。
    *   **Layer B（本音）:** `Wabi-sabi garden structures` などを指定し、日本庭園とグロテスクなアートインスタレーションを融合させた高精細画像を生成。
*   **AIからの出力と選定:** 各エピソードの意図に沿った画像を生成させ、制作者が厳選。意図的なハルシネーションを「心理描写」として採用。
*   **成果物:** プロンプトテンプレートの完成、Layer AおよびLayer Bの画像各10点録（計20点）の生成完了。深度マップ（Depth Map）による立体視用データ抽出準備完了。

## 3. WebARの技術スタック選定と基盤構築（システム設計フェーズ）
**目的:** アプリ不要で、ブラウザ上で画像スキャンによるAR体験を実現する基盤を作る。

*   **人間の思考:** Layer Aの画像（マーカー）を読み込むと、視差を伴って奥にLayer Bが透けて見える体験を作りたい。
*   **AI（Gemini 3 Pro）への指示:** Webブラウザで完結する最適なARライブラリと実装方針の提案を要求。
*   **AIからの出力と実装:** 軽量な **「MindAR」 + 「A-Frame」 + 「Three.js」** の構成を提案し、カメラ起動、画像認識、オブジェクト重畳のベースとなるHTML構造を構築。
*   **成果物:** プロジェクトのベースコード作成、Target Imageのコンパイル処理完了。

## 4. コア演出：Anatomical Reveal Shaderの開発（シェーダー実装フェーズ）
**目的:** ただ画像が切り替わるのではなく、日常の皮膜が「有機的に蠢きながら裂ける」解剖表現を実装する。

*   **人間の思考:** 深度マップと傾きセンサーを活用し、皮膜が剥がれて奥の空間が見えるような生々しい表現が必要。
*   **AI（Gemini 3 Pro）への指示:** Three.jsの ShaderMaterial (GLSL) を用いて、深度ベースの視差（Parallax）と有機的ノイズ浸食（Simplex Noise）、色収差（Chromatic Aberration）を組み合わせたカスタムシェーダーの実装を要求。
*   **AIからの出力と調整:** 高度なシェーダーコードの生成と、モバイル端末でのジャイロのブレを抑える極限のスムージング処理（Lerpによる補間）の提案と実装。
*   **成果物:** 本作の要となる「解剖学的露見シェーダー（Anatomical Reveal Shader）」の統合。

## 5. インスタレーションアートとしての環境演出とUI実装（UI/UXフェーズ）
**目的:** メインのAR体験を支え、没入感を高めるためのUIと環境演出を作り込む。

*   **AIと協働した主な実装:**
    *   **浸透的ローディング:** 幾何学的なUIアニメーションと4段階のプログレスバーを融合したローディング画面の実装。
    *   **時間帯連動型演出（TimeBasedEnvironment）:** ユーザーのアクセス時刻（朝・昼・夕・夜）に応じて、テーマカラー（CSS変数）やテキストが動的に切り替わるシステム。
    *   **パーティクルシステム:** Canvas 2D APIを用い、端末のジャイロに連動して漂う「塵・花びら・光の粒子」を軽量に実装。
    *   **グラスモーフィズムUI:** ターゲット認識時に表示される、モダンな解説カードUIの構築。
*   **成果物:** アプリライクな洗練されたUI群と、静止画ではなく「生きている空間」としての演出のシステム化。

## 6. アンビエント音響とシアターモード（オーディオ・没入フェーズ）
**目的:** 視覚だけでなく、聴覚からも「沈黙の庭」の表現に没入させる。

*   **人間の思考:** 音声ファイルに依存せず、Web Audio APIだけでプロシージャル（自動生成）な環境音を作れないか。
*   **AI（Gemini 3 Pro）への指示と実装:** 
    *   `AmbientSound` システムの共同構築（ピンクノイズの「雨音」、オシレーターによる深い「ドローン（倍音）」、FM合成でのランダムな「鳥の声」、リバーブによる空間形成）。
    *   「没入モード」として、環境音と合わせて詩のフラグメントが空間を漂う「シアターモード」の実装。
*   **成果物:** プロシージャルなアンビエント音響システムと、視覚・聴覚が統合されたシアター体験の完成。

## 7. デプロイ・パフォーマンス最適化（最終フェーズ）
**目的:** 全ての機能がモバイルブラウザ上でスムーズに動作するよう最適化する。

*   **AIとの協働による改善:** 
    *   大量の高解像度テクスチャ（画像と深度マップ）によるメモリクラッシュを防ぐため、遅延ロードとキャッシュ機構（`textureCache`）の実装。
    *   進行状況に応じた「シード（種子）」インジケーターの追加、および全体のバグ修正とリファクタリング。
*   **成果物:** WebAR版の実装完了、実機テストのクリア。

---

### アートとエンジニアリングの融合
本作は、詩的なメタファー、AIによる画像生成、WebAR技術、センサー連動、GLSLシェーダー、プロシージャルオーディオという多岐にわたる専門技術を必要としました。AIを単なるツールとしてではなく、論理的設計と感覚的表現を橋渡しする「クリエイティブパートナー」としてフル活用することで、個人制作の限界を超えたプロダクトレベルのWebAR体験を実現することができました。
