## 1. Anatomical Reveal Shaderの実装

### コンセプト
「表層（日常/Layer A）が、内圧（本音/Layer B）によって有機的に浸食され、裂け目から深淵が覗く」という概念を、Three.jsのカスタムシェーダーで実装。

**技術スタック:**
- Three.js ShaderMaterial
- GLSL（頂点シェーダー・フラグメントシェーダー）
- Simplex Noise（シンプレックスノイズ）
- Depth Map（深度マップ）
- Device Orientation API（ジャイロセンサー）

### 構造図

```
┌─────────────────────────────────────────┐
│   Anatomical Reveal Shader              │
├─────────────────────────────────────────┤
│                                         │
│  【Input】                              │
│  - Layer A (日常の写真)  ─┐            │
│  - Layer B (本音の庭)   ──┼→ 【フラグメント │
│  - Depth Map (深度情報) ──┤   シェーダー】 │
│  - Gyro Data (傾き角度)   │            │
│  - Time (時間経過)        │            │
│                          │            │
│  【Processing】          ↓            │
│  1. 視差マッピング        │            │
│  2. 有機的ノイズ浸食      │            │
│  3. 色収差エフェクト      │            │
│  4. エッジ発光            │            │
│  5. 角丸マスク適用        │            │
│                          │            │
│  【Output】              ↓            │
│  統合RGBA色              │            │
│  （Layer A/B合成 + 発光） │            │
└──────────────────────────────────────────┘
```

### Uniforms（シェーダーパラメータ）

| Uniform名 | 型 | 役割 | デフォルト |
|------------|-----|------|----------|
| `uTexA` | sampler2D | Layer A（日常）テクスチャ | null |
| `uTexB` | sampler2D | Layer B（本音）テクスチャ | null |
| `uDepth` | sampler2D | 深度マップ | null |
| `uTime` | float | 時間経過（秒） | 0.0 |
| `uParallax` | float | 視差強度 | 0.15 |
| `uReveal` | float | 露見度（0.0=Layer A, 1.0=Layer B） | 0.0 |
| `uViewVec` | vec3 | ジャイロベースの視線方向 | (0,0,1) |
| `uEdgeColor` | vec3 | 発光色（RGB） | #00ffaa |
| `uHasDepth` | float | Depth Map有効フラグ | 0.0 |

### フラグメントシェーダーの処理フロー

#### **ステップ1: 視差マッピング (Parallax Mapping)**

```glsl
// 深度値の読み取り（白=手前, 黒=奥）
float depthVal = texture2D(uDepth, vUv).r;

// 視線方向に基づいた オフセット計算
// 奥（黒）ほど大きく動く
vec2 parallaxOffset = viewDir.xy * ((1.0 - depthVal) * uParallax * -0.2);

vec2 uvB = vUv + parallaxOffset;  // Layer B用UV（ズレ適用）
vec2 uvA = vUv;                   // Layer A用UV（ズレなし）
```

**実装の意図:**
- ジャイロセンサーで端末の傾きを検出し、その方向に沿ってLayer Bがズレて見える
- 深度マップの暗い部分（奥）ほど大きくズレ、立体感が生まれる
- これにより「皮膚が剥がれ、奥が見える」という視覚効果を実現

#### **ステップ2: 有機的ノイズ浸食 (Organic Noise Reveal)**

```glsl
// Simplex Noise の生成
float noiseVal = snoise(vUv * 2.5 + vec2(0.0, uTime * 0.05));

// マスク値の計算（なめらかな遷移）
float mask = uReveal + (noiseVal * 0.1);

// 深度マップを活用：奥（黒）から露見が始まる演出
float depthFactor = 1.0 - depthVal;  // 黒（奥）= 1.0
mask = smoothstep(0.4, 0.6, mask * 1.2 - depthFactor * 0.2 * uHasDepth);
```

**実装の意図:**
- `Simplex Noise`により、Layer A/B のボーダーが「生きている」かのように蠢く
- 単純な直線的な遷移ではなく、有機的な不規則性により「庭の根が浸食する」表現
- `smoothstep()`で滑らかな階段関数を実現し、ぎざぎざではなくなめらかな境界線

#### **ステップ3: 色収差エフェクト (Chromatic Aberration)**

```glsl
// RGB各チャンネルを微小にズラしてサンプリング
float aber = 0.005 * uParallax;
float r = texture2D(uTexB, uvB + vec2(aber, 0.0)).r;    // 赤：右にズレ
float g = texture2D(uTexB, uvB).g;                       // 緑：そのまま
float b = texture2D(uTexB, uvB - vec2(aber, 0.0)).b;    // 青：左にズレ

vec4 colorB = vec4(r, g, b, 1.0);
```

**実装の意図:**
- 現実とデジタルの狭間を視覚的に強調
- カメラレンズの色ズレを表現し、「破綻した現実」感を演出
- RGB各チャンネルの微妙なズレにより、違和感と美しさが共存

#### **ステップ4: エッジ発光 (Edge Emission)**

```glsl
// マスク値の境界部分でのみ発光
float edge = smoothstep(0.0, 0.1, mask) * (1.0 - smoothstep(0.9, 1.0, mask));
vec3 edgeEmission = uEdgeColor * edge * 2.0;

// Layer A と Layer B の合成
vec4 finalColor = mix(colorA, colorB, mask);
finalColor.rgb += edgeEmission;  // 境界線の発光追加
```

**表現の意図:**
- 日常と本音の境界が「エネルギーを放つ」ように見える
- アクセントカラー（デフォルト: #00ffaa のモスグリーン）により、庭のテーマを強化

#### **ステップ5: 角丸マスク＆フェード境界**

```glsl
// 画面全体をマスク（角が丸い）
float roundMask = roundedRectMask(vUv, cornerRadius: 0.08, feather: 0.03);

// 四隅のボーダー発光
float borderGlow = (1.0 - roundMask) * smoothstep(0.0, 0.05, roundMask) * 0.5;
finalColor.rgb += uEdgeColor * borderGlow;

finalColor.a = roundMask;  // 透明度マスク
```

**実装の意図:**
- 画面を角丸フレーム内に制限し、デジタルインターフェースの枠を強調
- フェード幅を調整することで、ソフトな境界を実現

## 2. 時間帯連動環境演出

### TimeBasedEnvironment クラス

**概要:** ユーザーのアクセス時刻に応じて、色彩・テーマ・ローディングテキストが自動変更される。

```javascript
class TimeBasedEnvironment {
    constructor() {
        this.currentPeriod = this.getTimePeriod();  // 時刻判定
        this.applyEnvironment();                     // スタイル適用
    }
    
    getTimePeriod() {
        const hour = new Date().getHours();
        if (hour >= 5 && hour < 10) return 'morning';  // 朝: 5-10時
        if (hour >= 10 && hour < 17) return 'day';     // 昼: 10-17時
        if (hour >= 17 && hour < 20) return 'evening'; // 夕: 17-20時
        return 'night';                                 // 夜: 20-5時
    }
}
```

### タイムテーマ定義

| 時間帯 | アクセント色 | グラデーション背景 | ローディングテキスト |
|--------|-------------|------------------|-------------------|
| **morning** (5-10h) | 象牙色 rgba(220,220,200) | 青みがかった灰色 | 「朝靄に、言えなかった言葉が滲む...」 |
| **day** (10-17h) | 錆びた青磁色 rgba(100,160,150) | 深い緑味の黒 | 「白昼の静寂は、何よりも雄弁だ...」 |
| **evening** (17-20h) | 乾いた煉瓦色 rgba(180,100,80) | 赤茶けた闇 | 「夕闇が、拒絶と包容を混ぜ合わせる...」 |
| **night** (20-5h) | 深い鉄紺 rgba(80,100,180) | ほぼ漆黒の青 | 「夜の底で、沈黙は呼吸を始める...」 |

### 実装メカニズム

```javascript
applyEnvironment() {
    const root = document.documentElement;  // :root
    const theme = themes[this.currentPeriod];
    
    // CSS変数を動的更新
    root.style.setProperty('--time-accent', theme.accent);
    root.style.setProperty('--time-accent-dim', theme.accentDim);
    
    // ローディング背景の更新
    const loadingBg = document.getElementById('custom-loading');
    if (loadingBg) {
        loadingBg.style.background = theme.gradient;
    }
    
    // ローディングテキストの更新
    const loadingText = document.getElementById('loading-main-text');
    if (loadingText) {
        loadingText.textContent = theme.welcomeText;
    }
}
```

**演出的効果:**
- 訪問時刻が作品の心象世界を映し出す
- 同じコンテンツでも「時間」という変数により毎回異なる体験
- 日本的な四季観と時刻感を色彩で表現（侘び寂びの美学）

## 3. パーティクルシステム

### ParticleSystem クラス

**目的:** Canvas 2D APIを用いた効率的なパーティクル表現  
**パーティクル総数:** 35個（CPU負荷とビジュアルのバランス）

#### パーティクル構造体

```javascript
{
    x, y,                    // 座標
    size,                    // サイズ（3-8px）
    speedX, speedY,          // 移動速度
    opacity,                 // 不透明度（0.1-0.5）
    type,                    // 'petal' | 'light' | 'dust'
    rotation,                // 回転角度（0-2π）
    rotationSpeed,           // 回転速度（±0.02 rad/frame）
    pulse,                   // パルスアニメーション用（位相）
    color                    // RGBカラー文字列
}
```

#### パーティクル種別と視覚特性

| タイプ | 色彩 | モーション | 表現 |
|--------|------|----------|------|
| **petal** | 苔色RGB(120-140, 140-155, 100-120) | ゆっくり回転上昇 | 庭の落ち葉・花びら |
| **light** | 銅色RGB(140-160, 115-130, 95-115) | 浮遊 | 古い建築の錆・光 |
| **dust** | 白RGB(255, 255, 255) | 微動 | 塵埃・空間感 |

### パーティクルの更新と描画

#### 更新フロー

```javascript
update() {
    this.particles.forEach((p, index) => {
        // 移動（ジャイロオフセットも適用）
        p.x += p.speedX + this.gyroOffset.x * 0.01;
        p.y += p.speedY + this.gyroOffset.y * 0.005;
        
        // 回転・パルス更新
        p.rotation += p.rotationSpeed;
        p.pulse += 0.02;
        
        // 画面外判定＆リセット
        if (p.y < -20 || p.x < -20 || p.x > canvas.width + 20) {
            this.particles[index] = this.createParticle();
            this.particles[index].y = canvas.height + 10;
        }
    });
}
```

#### 描画フロー（Petal/Light/Dust の区別）

```javascript
draw() {
    this.ctx.clearRect(0, 0, width, height);
    
    this.particles.forEach(p => {
        this.ctx.save();
        this.ctx.translate(p.x, p.y);
        this.ctx.rotate(p.rotation);
        
        // パルスオパシティ（時間とともに明滅）
        const pulseOpacity = p.opacity * (0.7 + Math.sin(p.pulse) * 0.3);
        
        if (p.type === 'petal') {
            // 楕円形（花びらシェイプ）
            this.ctx.beginPath();
            this.ctx.ellipse(0, 0, p.size * 0.6, p.size, 0, 0, 2π);
            this.ctx.fillStyle = p.color + pulseOpacity + ')';
            this.ctx.fill();
            
            // 光彩（soft glow）
            this.ctx.shadowBlur = 8;
            this.ctx.shadowColor = p.color + '0.3)';
            
        } else {
            // 光の粒子：ラジアルグラデーション
            const grad = this.ctx.createRadialGradient(0,0,0, 0,0,p.size);
            grad.addColorStop(0, p.color + pulseOpacity + ')');
            grad.addColorStop(1, p.color + '0)');
            
            this.ctx.beginPath();
            this.ctx.arc(0, 0, p.size, 0, 2π);
            this.ctx.fillStyle = grad;
            this.ctx.fill();
        }
        
        this.ctx.restore();
    });
}

animate() {
    this.update();
    this.draw();
    requestAnimationFrame(() => this.animate());  // 60fps
}
```

### ジャイロ連動

```javascript
updateGyro(x, y) {
    // ジャイロの傾き角度をピクセル単位のオフセットに変換
    this.gyroOffset.x = x * 15;  // 左右傾きを増幅
    this.gyroOffset.y = y * 15;  // 前後傾きを増幅
}
```

**視覚的効果:**
- パーティクルが端末の傾きに応じて左右に流れ、没入感を強化
- 微妙な動きので気配的演出

## 4. ジャイロスコープ視差効果

### GyroParallax クラス

**目的:** Device Orientation APIで端末の傾きを検出し、Depth Mapの視差効果に反映

#### デバイス方向検出

```javascript
class GyroParallax {
    init() {
        if (window.DeviceOrientationEvent) {
            // iOS 13+ では許可が必要（ユーザーインタラクション後）
            if (typeof DeviceOrientationEvent.requestPermission === 'function') {
                this.needsPermission = true;
            } else {
                this.startListening();
            }
        }
    }
    
    async requestPermission() {
        try {
            const permission = await DeviceOrientationEvent.requestPermission();
            if (permission === 'granted') {
                this.startListening();
            }
        } catch (e) {
            console.log('Permission denied:', e);
        }
    }
}
```

#### イベントリスナー

```javascript
startListening() {
    window.addEventListener('deviceorientation', (e) => {
        // beta: 前後の傾き (-180 to 180)
        // gamma: 左右の傾き (-90 to 90)
        this.beta = (e.beta || 0) / 180;   // 正規化: -1.0 ~ 1.0
        this.gamma = (e.gamma || 0) / 90;  // 正規化: -1.0 ~ 1.0
        
        if (this.callback) {
            this.callback(this.gamma, this.beta);
        }
    });
}
```

### グローバル データフロー

```
deviceorientation event
        ↓
   GyroParallax
        ↓
window.gyroData = { gamma, beta }
        ↓
    ┌──┴──────────────────┬────────────────┐
    ↓                     ↓                 ↓
 Shader             ParticleSystem      ParallaxOffset
 (視差変形)         (粒子流れ)          (Layer B配置)
```

### Shader内での利用（再掲）

```glsl
if (window.gyroData) {
    const gx = window.gyroData.gamma;  // 左右傾き
    const gy = window.gyroData.beta;   // 前後傾き
    
    // 目標ベクトル
    const targetVec = new THREE.Vector3(gx * 1.2, gy * 0.9, 1.0);
    
    // スムージング補間（極低速で震え防止）
    this.smoothedViewVec.lerp(targetVec, 0.002);
    
    // シェーダーに渡す
    this.material.uniforms.uViewVec.value.copy(this.smoothedViewVec);
}
```

**スムージングの重要性:**
- 補間係数 `0.002` という極限まで低い値により、ジャイロセンサーのノイズによる振動を平滑化
- Lerp(線形補間)で滑らかな変形を実現

## 5. アンビエント音響システム

### AmbientSound クラス

**目的:** Web Audio APIを用いた複層的な環境音の動的合成  
**構成要素:**
1. ピンクノイズ（雨音）
2. ドローン（深い倍音）
3. 風のノイズ
4. 水滴音（ランダム）
5. 鳥の声（ランダムFM合成）
6. ベル・風鈴
7. 木のきしみ

### オーディオグラフ構造

```
┌────────────────────────────────────────────────┐
│          AudioContext (Sample Rate)             │
└────────────────────────────────────────────────┘
        ↓
┌────────────────────────────────────────────────┐
│  Reverb (Convolver + Gain 0.3mix)              │
└────────────────────────────────────────────────┘
        ↓
┌────────────────────────────────────────────────┐
│      Master Gain (0.12 = 適度に控えめ)         │
└────────────────────────────────────────────────┘
        ↓
   Destination (スピーカー)
```

### 各音源の詳細

#### 1. リバーブノード (Convolver)

```javascript
createReverbNode() {
    // 2.5秒のインパルス応答を生成
    const length = sampleRate * 2.5;
    const impulse = audioContext.createBuffer(2, length, sampleRate);
    
    // 減衰関数で有機的な残響を模擬
    for (let i = 0; i < length; i++) {
        const decay = Math.exp(-i / (sampleRate * 0.8));  // 指数減衰
        impulseL[i] = (Math.random() * 2 - 1) * decay;
        impulseR[i] = (Math.random() * 2 - 1) * decay;
    }
    
    this.reverbNode = audioContext.createConvolver();
    this.reverbNode.buffer = impulse;
    this.reverbGain.gain.value = 0.3;  // ドライ/ウェット比
}
```

**表現:** 庭の奥行きを音で表現。全ての音がリバーブを通ることで、「深い空間」感を演出。

#### 2. ピンクノイズ（雨音）

```javascript
createRainNoise() {
    // ポール-マッカートニー法でピンクノイズ生成
    let b0, b1, b2, b3, b4, b5, b6 = 0;
    for (let i = 0; i < bufferSize; i++) {
        const white = Math.random() * 2 - 1;
        b0 = 0.99886 * b0 + white * 0.0555179;
        b1 = 0.99332 * b1 + white * 0.0750759;
        // ... (詳細な係数計算)
        output[i] = (b0 + b1 + ... ) * 0.05;
    }
    
    // ローパスフィルター（400Hzで高周波カット）
    const filter = audioContext.createBiquadFilter();
    filter.type = 'lowpass';
    filter.frequency.value = 400;
    
    noise.connect(filter);
    filter.connect(noiseGain);
    noiseGain.connect(masterGain);  // ドライパス
    noiseGain.connect(reverbNode);  // ウェットパス
}
```

**特性:**
- ホワイトノイズより低周波が多い（1/f ゆらぎ）
- 雨音・風音に自然
- マスター音量の約40%（主要背景音）

#### 3. ドローン（深い倍音）

```javascript
createDrone() {
    // 基本周波数: 55Hz（A1, バイオリンの低音域）
    const frequencies = [55, 110, 165, 220, 330];
    
    frequencies.forEach((freq, i) => {
        const osc = audioContext.createOscillator();
        osc.frequency.value = freq + (Math.random() - 0.5) * 0.5;  // 微弱なデチューン
        
        // LFOで周波数を時間変化
        const lfo = audioContext.createOscillator();
        lfo.frequency.value = 0.05 + Math.random() * 0.1;  // 0.05-0.15Hz
        lfo.connect(gainNode.frequency);  // 周波数モジュレーション
        
        const gain = audioContext.createGain();
        gain.gain.value = 1 / (i + 1);  // 倍音は小さく
    });
}
```

**表現:** お輪（おりん）やシンギングボウルのような深い共鳴。瞑想的・内省的な雰囲気を演出。

#### 4. 鳥の声（FM合成）

```javascript
playBirdChirp() {
    const carrier = audioContext.createOscillator();
    const modulator = audioContext.createOscillator();
    
    // 周波数モジュレーション
    const baseFreq = 2000 + Math.random() * 1500;
    carrier.frequency.value = baseFreq;
    
    modulator.frequency.value = 10 + Math.random() * 20;  // モジュレーション周波数
    modulator.connect(modGain);
    modGain.connect(carrier.frequency);  // 周波数を時間変化させる
    
    // 短いチャープ（0.15秒）
    const now = audioContext.currentTime;
    birdGain.gain.exponentialRampToValueAtTime(0.001, now + 0.15);
    
    // ランダムな間隔で次の鳥を生成
    const nextChirp = setTimeout(() => {
        this.playBirdChirp();
    }, 15000 + Math.random() * 25000);
}
```

**特性:**
- FM合成で単純なサイン波から複雑な倍音を素早く生成
- ランダムな周波数・タイミングで自然な多様性
- 日中から午後の特定エピソードで有効

#### 5. フィルター設計（風音の例）

```javascript
createWindNoise() {
    // ハイパスフィルター（低音カット）
    const windHPFilter = audioContext.createBiquadFilter();
    windHPFilter.type = 'highpass';
    windHPFilter.frequency.value = 300;  // 300Hz以下をカット
    
    // バンドパスフィルター（中高域強調）
    const windFilter = audioContext.createBiquadFilter();
    windFilter.type = 'bandpass';
    windFilter.frequency.value = 1200;  // 中心周波数
    windFilter.Q.value = 0.4;  // 帯域幅
    
    // LFOで風の強弱を表現
    const windLFO = audioContext.createOscillator();
    windLFO.frequency.value = 0.08;  // 0.08Hz = 周期約12秒
    windLFO.connect(windLFOGain);
    windLFOGain.connect(windGain.gain);  // ゲインを時間変化
}
```

## 結論

本システムは、複数の表現技術（3D Graphics, Canvas, Web Audio, CSS Animation, Sensor API）を統合し、「沈黙が庭になる」というメタファーを多感覚的に実現しています。

**技術的な特異性:**
- **有機的な視覚変形:** Simplex Noiseによる、生きた境界線表現
- **多層オーディオ:** プロシージャルサウンドによる環境音の動的合成
- **デバイス感応性:** ジャイロセンサーとの緊密な連携で、没入感を拡張
- **時間的変動性:** 訪問時刻により変わる色彩世界で、リプレイ価値を提供

ユーザーの物理的アクション（端末傾け、タップ、アクセス時刻）が、デジタル空間の「心象風景」に直接的に影響する関係を、技術的に構築しています。

## 用語集：主要技術概念

### グラフィックス関連

#### **Shader（シェーダー）**
GPU上で実行される特殊なプログラム。頂点や画素ごとの処理を並列化して高速実行。本作では色・形状・光の計算をリアルタイムで行う。

#### **GLSL（OpenGL Shading Language）**
GPUプログラミング言語。WebGL経由でブラウザで実行可能。C言語に似た文法。

#### **Three.js ShaderMaterial**
Webブラウザで3D表現を可能にするJavaScriptライブラリThree.jsの一機能。カスタムシェーダーコードを組み込めるマテリアル（材質）クラス。

#### **Vertex Shader（頂点シェーダー）**
3Dモデルの各頂点に対して実行されるシェーダー。頂点の位置、ノーマル（法線）、色などを変形・計算。本作では頂点座標を画面上の位置に投影。

#### **Fragment Shader（フラグメントシェーダー）**
画面上の各ピクセル（フラグメント）に対して実行されるシェーダー。最終的な色を決定。本作の「解剖」表現の中核。

#### **Uniform（ユニフォーム）**
シェーダーに外部から渡されるパラメータ。全頂点・全ピクセルで共通の値（テクスチャ、時間、カラーなど）。

#### **Depth Map（深度マップ）**
画像の各ピクセルに「奥行き情報」を格納した画像。白=手前、黒=奥。本作では視差効果と「奥から露見する」表現に使用。

#### **Parallax Mapping（視差マッピング）**
Depth Mapを参照し、視線角度に応じてテクスチャUV座標（サンプリング位置）をズラす技術。凹凸感を立体的に表現する古典的な手法。

#### **Simplex Noise（シンプレックスノイズ）**
Perlin Noiseの改良版。計算効率に優れ、自然な波状パターンを生成。火、雲、液体などの有機的な表現に用いられる。本作では「庭の根が浸食する」境界線の生成に使用。

#### **Chromatic Aberration（色収差）**
光学カメラレンズの色ズレ現象を模擬。RGB各チャンネルを微妙にズラして合成。デジタルと現実の境界を強調。

#### **PlaneGeometry**
Three.jsの基本形状。平面（矩形）ポリゴンを定義。32×32に分割することで、各頂点単位での変形が可能になる。

### アニメーション・DOM関連

#### **Canvas 2D API**
HTML5 Canvas要素に2D描画を行うJavaScript API。ピクセル単位での描画が高速。本作ではパーティクルシステムに使用。

#### **requestAnimationFrame**
ブラウザのリフレッシュレート（通常60fps）に同期したアニメーションフレームを要求する関数。過度なフレームレートを避け、CPU効率を最適化。

#### **CSS Variables（CSS カスタムプロパティ）**
CSSで定義可能な変数。`:root` で定義すれば全要素で使用可能。JavaScriptで動的に値を変更できるため、テーマ切り替えに便利。

#### **Lerp（線形補間）**
2つの値を線形に補間する手法。$\text{result} = a + (b - a) \times t$。本作ではジャイロ揺らぎを滑らかに、スムージング係数0.002で超低速補間。

#### **setProperty / style.setProperty**
JavaScriptでCSS変数を動的に更新するメソッド。
```javascript
root.style.setProperty('--accent-color', 'rgba(120, 140, 100, 0.9)');
```

### オーディオ関連

#### **Web Audio API**
ブラウザでオーディオの合成・処理を行うJavaScript API。オシレーター、フィルター、ゲイン、リバーブなどの「ノード（Node）」を組み立てる。

#### **AudioContext**
Web Audio APIの中核。全ての音声処理はこのコンテキスト内で行われる。Oscillator、Filter、Gain などのノードを作成・接続。

#### **Oscillator（オシレーター）**
特定の周波数を持つ波形を生成するノード。波形タイプ：sine（正弦波）、square（矩形波）、triangle（三角波）、sawtooth（のこぎり波）。

#### **Gain（ゲイン）**
音量（振幅）を調整するノード。複数のGainノードを階層的に接続して、全体またはグループごとの音量制御が可能。本作ではマスターゲイン・個別ゲイン・サブゲイン（リバーブミックス）の3層構造。

#### **BiquadFilter**
フィルター処理を行うノード。複数のフィルタータイプ：
- **lowpass**: 高周波をカット（雨音の落ち着き）
- **highpass**: 低周波をカット（風音のシャープさ）
- **bandpass**: 特定周波数帯域のみを通す（風音の中高域強調）

#### **Convolver（コンボルバー）**
インパルス応答を用いたリバーブ・エコー処理。リアルな空間響を実現。本作では2.5秒の減衰インパルスを使用。

#### **ピンクノイズ（Pink Noise）**
周波数が低いほど大きい電力スペクトルを持つノイズ。1/f ゆらぎとも呼ばれる。ホワイトノイズより自然で、雨音・風音に適している。

#### **FM合成（Frequency Modulation Synthesis）**
モジュレータ波（低周波）で、キャリア波（高周波）の周波数を時間変化させる合成。複雑な倍音を素早く生成可能。本作では鳥の声に使用。

#### **LFO（Low Frequency Oscillator）**
約20Hz以下の低周波オシレーター。音量や周波数をゆっくり変調させるために使用。本作では「ドローンの複雑な響き」「風の強弱」に使用。

#### **インパルス応答（Impulse Response）**
「パチッ」という短い音（インパルス）に対するシステムの応答。Convolverでその応答を記録し、任意の入力音に適用すればリバーブが実現。

### センサー・入力関連

#### **Device Orientation Event**
スマートフォンの傾き角度を検出するWebAPI。`beta`（前後傾き）と `gamma`（左右傾き）を提供。iOS 13+では明示的な許可が必要。

#### **DeviceOrientationEvent.requestPermission()**
iOS 13+でジャイロセンサーへのアクセスを明示的に許可するメソッド。ユーザーインタラクション（タップなど）の後にのみ呼び出し可能。

#### **Beta & Gamma（傾き角度）**
- **beta**: 前後傾き（-180〜180°）。デバイスをス前下に傾けるとプラス。
- **gamma**: 左右傾き（-90〜90°）。デバイスを右に傾けるとプラス。

### 数学・アルゴリズム関連

#### **smoothstep() 関数**
0から1への滑らかな階段関数。シェーダーで頻出。
$$\text{smoothstep}(e_0, e_1, x) = \begin{cases} 0 & (x < e_0) \\ 1 & (x > e_1) \\ 3x^2 - 2x^3 & (e_0 \le x \le e_1) \end{cases}$$
ぎざぎざした遷移をなめらかに。

#### **Mix（ブレンド）**
2つの値を線形補間。`mix(a, b, t) = a * (1-t) + b * t`。本作ではLayer A/B の合成に使用。

#### **Radial Gradient（ラジアルグラデーション）**
中心から放射状に色が変わるグラデーション。Canvas 2D APIで「光の粒子」の柔らかい輪郭を表現。

#### **指数減衰（Exponential Decay）**
$y = e^{-x/\tau}$ の形。時間とともに指数的に減少。音量エンベロープ（フェードアウト）やインパルス応答の減衰に使用。

#### **Detuning（デチューン）**
周波数を微妙にズラす。複数オシレーターを同じ周波数でデチューンさせると、豊かな倍音（厚い音）が生まれる。本作ではドローンの複雑さを演出。

#### **Buffer / BufferSource**
Web Audio APIで音声データを保持するオブジェクト。RAMに読み込まれ、高速に再生可能。

#### **Loop（ループ再生）**
音声バッファの再生終了後、自動的に最初に戻る。環境音（雨、風）のように終わりのない音に使用。

- パーティクル数を35個に制限（モバイル対应）

### デザイン・表現関連

#### **わびさび（Wabi-Sabi）**
日本的美学。不完全性、無常、侘しさの中に美しさを見出す。本作の色彩・テーマの基礎。

#### **レイヤー構造（Layer A / Layer B）**
- **Layer A**: 日常のスナップ写真（表皮・防御）
- **Layer B**: 本音の庭（真皮・本質）

ARスキャンでこの二層が融合するリメタファー。

#### **ポラロイドキャプション形式**
チェキ写真のような2文構成の短いテキスト。日常と本音を簡潔に対置。

#### **タイム・テーマ（朝・昼・夕・夜）**
訪問時刻に応じて色彩世界が変わる。同じ作品を複数回訪問すると異なる心象体験ができる設計。

#### **Ambient Sound（アンビエント音響）**
背景音効。スピーカーのような定位音ではなく、周囲を包み込む環境音。瞑想的・没入的な雰囲気を演出。
