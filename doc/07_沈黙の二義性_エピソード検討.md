## 1. 主題 ── 言葉なき2者の、二義性

現行10話は、沈黙を **「不可視の愛」= 拒絶ではない何か**（支柱・檻・化石・種…）として一方向に読み解き、
エピローグも「私たちが選んだ沈黙は、拒絶の壁ではなかった」と沈黙を肯定的に**回収**している。

ここで描きたいのは、**言葉なき2者の空間が正反対に読めてしまう二義性**である。
とりわけ核に据えたい情感は ──

> **あえて言葉にしないでくれた思いやりによる、救われたと想える気持ち。**

つまり「彼は、何も言わなかった」という同じ沈黙が、

- **救い（γ）**：本当は言えたはずの一言を、相手が優しさから飲み込んでくれた。その沈黙に、私は救われている。
- **断絶（β）**：相手を想うことすら諦めた、声のない放棄。

という真逆の心象へ裂ける。本作の「日常（LayerA）が裂けて本音の庭（LayerB）が露見する」**解剖＝露見構造**そのものと、
極めて相性がよい。露見するのは**事実ではなく解釈**である、という一段深いメッセージになる。

### 抽象度の原則（重要）
感情語（救い・思いやり・諦め・孤独）は **一切名指さない**。
既存話（Ep01「私は、訊かなかった」/ Ep10「芽吹かせないことも、ひとつの約束だった」）に倣い、
**置かれた物**と**しなかった所作**（上げなかった鋏・掃かない落ち葉・訊かないでおいた沈黙）だけを描き、
ニュアンスは読み手の裡にかすかに立ち上がるに任せる。γとβの差は、断言ではなく**手つきの温度**で分ける。

### 沈黙のグラデーション（庭の三相）

| 極 | 情感 | 沈黙の質 | 庭 |
|---|---|---|---|
| **γ 救い（本命）** | あえて言わないでくれた思いやり／救われた | 能動的に飲み込まれた言葉 | 鋏を上げなかった庭 |
| α 調和 | 話さずとも通じ合う午後 | 相互の、もう要らない言葉 | 掃かなくていい庭 |
| β 断絶 | 想うことすら諦めた気まずさ | 放棄された言葉 | 道の消えた庭 |

## 2. 推奨案：γ↔β の対（2話）── 「言わなかった」の裏表

γとβを、**それぞれ独立した LayerA＋LayerB の完結エピソード**として用意する。

- 日常（LayerA）は「茶／湯呑み」を共有モチーフに ── γ=*温かい茶を淹れて運ぶ* ↔ β=*冷めた茶に手を伸ばさない*
- 本音（LayerB）は「枝と剪定鋏」を共有モチーフに ── γ=*閉じて置かれた鋏* ↔ β=*開いて錆びた鋏*

既存 Ep08「庭師の剪定」・Ep01「矯正する支柱」を**反転**させる設計。感情語は一切名指さない。

### ★本命：Episode γ ─ 救いの庭（あえて言葉にしない思いやり）

**[Photo Caption / 日常（LayerA）]**
```
その日、私は、ひとつ間違えた。
彼は湯呑みを二つ、盆にのせて、こちらへ来た。
それについては、最後まで、何も。
```
※「気づいていた」等の説明を排し、事実の観察だけに留める。沈黙は「何も。」の余白で示す。

**[AR Layer / 本音と庭（LayerB）]**
```
歪んだまま伸びた枝が、ひとつ。
そのすぐ横に、閉じたままの鋏が、置かれていた。
切らなかった理由を、私は、訊かないでおいた。
```
強調キーワード＝「訊かないでおいた」。
Ep08「庭師の剪定」の**逆**。「救い」とは書かない。**閉じた鋏**と**訊かない沈黙**だけで、赦しがかすかに滲む。
Ep01「私は、訊かなかった」と同じ手つきで結ぶ。

### Episode β ─ 放棄の庭（想うことをやめた沈黙）

**[Photo Caption / 日常（LayerA）]**
```
同じ食卓に、私たちは向かい合っていた。
彼の湯呑みは、いつからか、冷めきっていた。
それに手を伸ばすことも、もう、しなかった。
```
※γの「温かい茶を運ぶ」と対。冷めた茶＝交わされなくなった気遣い。断絶とは書かない。

**[AR Layer / 本音と庭（LayerB）]**
```
折れた枝が、ひとつ。
そのすぐ横で、鋏は、開いたまま錆びていた。
切らなかった理由さえ、もう、どこにもなかった。
```
強調キーワード＝「どこにもなかった」。

### 鏡像の設計
両話とも LayerA=「茶／湯呑み」、LayerB=「枝がひとつ／傍らの鋏／切らなかった」で構成し、差はただ ──

- γ = **温かい茶＋閉じて置かれた鋏** ＋ *訊かないでおいた*（意志ある沈黙）
- β = **冷めた茶＋開いて錆びた鋏** ＋ *理由さえどこにもない*（意志の消失）

── という**手つきの温度**だけ。感情は名指されず、読み手の裡でだけ分岐する。

## 3. 画像プロンプト

既存の2スタイルブロック（`doc/02`）を末尾に付す。Aspect Ratio 1:1。
固定パレット（moss greens / oxidized grays / pale stone whites / dried blood reds）は保ちつつ、
**光の暖かさ・鋏の扱い・枝の生死**で読みを分岐させる。

### LayerA γ（救いの日常）
*Concept:* 失敗を咎めず、黙って二つ目の茶を運ぶ。温かい湯気＝言葉にされない気遣い。
> `A quiet kitchen in soft, warm afternoon light. A partner carries a small tray with two cups of freshly poured tea, faint steam rising, walking toward the viewer. Gaze lowered, no words, but the second cup is unmistakably for the other person. On the counter, a small everyday failure left unremarked. A gentle, unspoken stillness.`
>
> **[日本語訳]** 午後の柔らかく暖かい光の台所。相手が盆に淹れたての茶を二つ、湯気を立てながらこちらへ運んでくる。視線は伏せ、言葉もないが、二つ目の湯呑みは確かに相手のためのもの。台所には触れられぬままの小さな失敗の跡。優しく、言葉にされない静けさ。

*Concept:* 冷めきった湯呑みに、もう手を伸ばさない。交わされなくなった気遣い。

> **[日本語訳]** 平坦で冷えていく午後の光の食卓。二人は向かい合って座るが、互いに少し背け、視線は交わらない。手前に、とうに冷めきった湯呑みがひとつ、表面に薄い膜を張り、手つかずのまま。隔たりの、澱んだ静けさ。

## 4. 変奏：α ─ 掃かなくていい庭（話さずとも通じ合う午後）

γ/βの対とは別に、**相互の・成熟した沈黙**（熟年夫婦の調和）を一枚で置きたい場合の案。

**[Photo Caption / 日常（LayerA）]**
```
日曜の、長い午後。
彼は縁側で新聞を、私はその隣で、繕いものをしていた。
交わす言葉は、ひとつも、要らなかった。
```

**[AR Layer / 本音と庭（LayerB）]**
```
飛び石を埋めていく落ち葉を、私たちは、掃かなくなった。
散ったままの庭を、どちらも、直そうとはしない。
それでいいのだと、たしかめ合ったことも、なかった。
```
「調和」「約束」とは書かない。*直そうとしない*・*たしかめ合わない*所作だけで、成熟した相互の沈黙をかすかに示す。
画像は落ち葉に覆われた飛び石、暖色・寄り添う二石（プロンプトは採用時に起こす）。

## 5. 代替案B：一話で二義性を抱える（1話）

対で見せず、**LayerB本文自体が両義を宿す**最小侵襲版。

```
あなたが言わずにおいたものを、
私は、名づけないままにしている。
それが何であれ、庭は、静かなままだった。
```
「救い／諦め」を並べて名指す直接版は避け、*名づけない*まま留める。
LayerAは推奨案γと共通。画像はγ寄り一枚、あるいは depth シェーダーの視点で表情が振れる曖昧な一枚。
**「露見しても、なお分からない」**という反‑解剖のオチになる。

## 6. モチーフのパレット（差し替え候補）

「言わなかった」を反転させられる庭メタファー：

- **剪定鋏（本命・上記）** … 上げなかった刃＝赦し／錆びて落ちた刃＝放棄。Ep08と直結。
- **二本の木の根** … γ:触れぬ二幹、地中で根が絡む／β:根も別々の方角へ。
- **蹲踞（つくばい）の水** … γ:波立たぬ水面に二人の顔を映したまま／β:涸れて、底に落ち葉だけ。
- **飛び石の落ち葉（変奏αで使用）** … 掃かない＝赦し／道が消える＝断絶。

## 7. 配置と余韻（既存アークとの統合）

- **配置**：Ep08「庭師の剪定」の直後、または Ep09「庭の全景」の直前が最適。
  「切る＝正す」を見せた後に「切らなかった＝赦した」を置き、**Episode 08.5「上げられなかった鋏」**として挿入。
- **エピローグの再緊張**：現行「拒絶の壁ではなかった」を、
  - (a) そのまま残し、二義性の直後に置く＝回収を"事実"から"二人の選択／祈り"へ変える、または
  - (b) 救いの含意を一句添える（例：「壁だったのかもしれない。それでもあなたは、鋏を上げなかった」）。
- **AR構造への収まり**：γとβはそれぞれ独立した LayerA＋LayerB を持つため、
  各MindARターゲットが `layerA_N.jpg` + `layerB_N.jpg` + `layerB_N_depth.png` を1対1で束ねる既存構造
  （`index.html` 3788行〜, `anatomical-reveal` 1769行〜）に**そのまま2ターゲットとして収まる**（特殊演出は不要）。
  二義性は「γとβが隣り合って展示される」体験全体で立ち上げる。
